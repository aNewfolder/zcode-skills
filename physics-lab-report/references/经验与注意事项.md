## 2026-09-21 Typora 批量导出的实操细节（实测 Typora 1.9.5，Windows）

- Typora **没有命令行导出**：`typora.exe xx.md --export xx.pdf` 会把 pdf 路径当成要打开的新文档，不要用。
- 可用的 GUI 自动化键序（聚焦 Typora 主窗口后）：`Escape` → `alt+f` → `Up`×4（定位到"导出"）→ `Right`（展开子菜单，默认高亮第一项 PDF）→ `Enter`。注意：子菜单里**第二项才是 HTML**，多按一次 Down 就会导成 HTML。
- 若目标 PDF **已存在**，保存时会弹"确认另存为"对话框，必须再点 `是(Y)`，否则导出被静默取消（文件保持旧版）。批量重导前直接删掉旧 PDF 更稳。
- 键序对新打开的窗口可能因初始化未完成而失效，重发一遍键序即可；发键前确保 Typora 是前台窗口（可用 SetForegroundWindow）。

## 2026-09-21 用户反馈（二）：导出自动化事故与确定性流程（覆盖 09-21 早间的 GUI 键序条目）

- **事故**：方向键数菜单的 GUI 自动化在菜单未弹开/焦点丢失时按键落到别的窗口或别的菜单项，实际造成过：导出成 HTML、点到"删除"（必做2 md 被删，靠 `%APPDATA%\Typora\draftsRecover` 恢复）、点到"打印"、点到"关闭"；导出中途强杀 Typora 还可能截断正在保存的文件。
- **正确做法（已固化为 `其他\_typora_export2.py`，SKILL.md 第 8 步已指向）**：
  1. 进程 DPI 感知 + 窗口钉到 (0,0) + AttachThreadInput 强制前台并循环验证；
  2. Alt+F 后**截图差分**确认文件菜单真的弹开，没弹开就 Esc 重试；
  3. 键盘 ↑×4 选中"导出" → → 展开子菜单（PDF 为首项自动高亮）；
  4. **按 Enter 前截图门禁**：必须在截图上找到子菜单"PDF"文字行，找不到就放弃本次点击（这杜绝了导出成 HTML）；
  5. 保存对话框是原生 #32770：EnumChildWindows 找 Edit → WM_SETTEXT 写完整路径 → 找"保存"按钮 → BM_CLICK；
  6. 导出后程序化校验：%PDF 魔数、页数 2~6、前 3 页字体含 SimSun/SimHei（主题未加载=裸排版，字体为空即废品）、体积下限（图片没加载出来）；
  7. 导出前备份 md、导出后比对，被改/被删立即恢复（Typora 强杀+自动保存会截断文件）。
- **其他坑**：tasklist 输出是 GBK，subprocess 解码要显式 `decode("gbk")`；64 位下 ctypes 调 SendMessageW/GlobalAlloc 必须先设 argtypes/restypes 否则句柄截断；pymupdf `doc.save()` 不允许原地覆盖，加页码要 `-o` 临时文件再替换；等厚干涉G/霍尔法/万用表三份的"注意事项"引用块会被分页拦腰截断，`break-inside:avoid` 被 Typora 打印管线无视，**有效解法是在 md 里该引用块前插 `<div style="page-break-before: always;"></div>`**（3 份已插）。
- **主题居中公式**：`物理实验.css` 末尾用 `p > mjx-container:first-child:has(+ script:last-child)` 实现公式块居中——打印 DOM 中 $$ 块是 `<p><mjx-container/><script type="math/tex">…</script></p>`，script 兄弟使 `:only-child` 永不匹配；行内公式与文字同段不满足该结构故不受影响。

## 2026-09-22 Typora 主题陷阱与 PicGo 改名对话框（导出 12 份预习报告时实测）

- **主题会被别的文档切走**：Typora 当前主题存在 `%APPDATA%\Typora\profile.data`（hex 编码的 JSON，键 `theme`）。本次发现被切成 `latex-light1.css`，导出的 PDF 字体为 STSong/Heiti、版式完全不对。
- **`_typora_export2.py` 的字体校验有盲区**：`latex-light1.css` 也含 SimSun/SimHei，字体校验能通过，但版式是另一套（封面栏出现"0.0.0.1"自动编号、标题双重编号、display 公式左对齐、署名行不居中）。**导报告前必须先把主题设为 `物理实验.css`**（杀 Typora → 改 profile.data → 导出），导完恢复原主题；校验除了字体，最好再抽查封面页 PNG。
- profile.data 改法：读出 hex → `json.loads(bytes.fromhex(hx))` → 改 `theme` → `json.dumps(..., ensure_ascii=False, separators=(',',':')).encode('utf-8').hex()` 写回；必须在 Typora 未运行时改，否则退出时被覆盖。
- **PicGo"上传前重命名"对话框的完整处理链**：`upload.py` 发请求 → 对话框挂起请求属正常（Electron 窗口，类 `Chrome_WidgetWin_1`，小写标题 `picgo`，a11y 树读不到内容）→ 用 computer-use 截图读预填时间戳文件名 → 按截图坐标点"确定" → `upload.py --resolve 本地图 --name 对话框里的文件名` 做 MD5 校验拿 URL。请求超时报 TIMEOUT 不要重发（会传重），resolve 即可。
- 课件截图带 PPT 米色底纹的处理：向内裁 6px 后把 `min(RGB)≥233 且 max−min≤14` 的像素漂白成纯白，底纹框即可彻底去除（惠斯登电桥电路图实测有效）。

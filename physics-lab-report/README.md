# physics-lab-report

让 AI 助手替你撰写浙江大学《大学物理实验》的预习报告与实验报告：Obsidian markdown 撰写、Typora 导出 PDF，严格遵循课程绪论 PPT 的不确定度评定与有效数字规范，杜绝任何 AI 痕迹。

## 功能与适用场景

本 skill 为浙江大学《大学物理实验》课程深度定制，供 AI 助手（如 ZCode、Claude Code 等遵循 SKILL.md 约定的框架）在以下场景使用：

- 用户发来实验原始数据照片、手写数据记录，要求"写报告""处理这次实验数据""出预习报告/实验报告"；
- 产出预习报告（综述/重点/难点，带字数红线）与实验报告（四板块按 10/50/30/10 给分结构）两种 md，Typora 导出 PDF；
- 全部数据处理用 `scripts/lab_calc.py` 按课程口径（五步法、最大误差限修约、四舍六入五凑偶、最小二乘优先）算出，再以"手算过程"誊进报告；
- 自动经超星下载当次实验讲义、插图一律走图床。

**注意**：报告模板、不确定度评定口径（绪论 PPT）、"学在浙大"提交流程、选课系统查教师/日期的流程均绑定浙大该课程。他校使用需自行改模板与计算规范（`references/计算规范.md`）。

## 依赖

| 依赖 | 说明 |
| --- | --- |
| Python 3.8+ | `scripts/lab_calc.py` **仅用标准库**（argparse/math/decimal），无需安装第三方包 |
| Typora | md 撰写与导出 PDF。配套的 `_typora_export2.py`（确定性导出脚本）、`给PDF加页码.py` 不在本仓库内，需自备；页码脚本依赖 pymupdf（`pip install pymupdf`） |
| picgo-image-upload skill | 报告插图一律传图床（本仓库内有该 skill），需先配置好 PicGo 图床 |
| chaoxing-courseware skill | 每次写作前从超星下载当次实验讲义（本仓库内有该 skill），需超星账号登录 |
| 选课系统查询脚本（可选） | `自动选课.py` 不在本仓库内，在校园网内查询各实验带课教师与上课日期用；没有就手动查询后填入课表模板 |

## 安装部署

1. 把本目录整体复制到你的 AI 助手技能目录。ZCode 为 `~/.zcode/skills/physics-lab-report/`；其他遵循 SKILL.md 约定的框架放到对应 skills 目录即可。
2. 确认 `python --version` 可用；按上表准备 Typora，并部署同仓库的 picgo-image-upload、chaoxing-courseware 两个 skill。
3. 在你的课程资料根目录（自选位置，如 `课程资料/大学物理实验/`）放入：报告模板（`物理实验报告-模板.md`、`物理实验预习报告-模板.md`，从课程组获取）、绪论 PPT、报告导出与页码脚本（如采用该流程）。
4. **首次使用前**，把 SKILL.md 里的个人信息占位符替换为你自己的信息（清单见下）。也可以不替换，AI 会在使用时向你询问。
5. 在 AI 助手里说"帮我写大物实验报告"即可触发；若无自动触发，直接引用 SKILL.md 让助手读取。

## 需要配置的信息

SKILL.md 中使用以下占位符，部署时建议一次性替换（或保留占位符，由 AI 首次使用时询问）：

| 占位符 | 含义 | 出现位置 |
| --- | --- | --- |
| `<你的姓名>` | 封面与 PDF 文件名 | 交付形态、成稿审查 |
| `<你的学号>` | 封面与 PDF 文件名（与姓名之间也有加号） | 同上 |
| `<你的班级>` | 封面班级栏 | 交付形态 |
| `<课程资料根目录>` | 你存放本课程全部资料的根目录 | 固定路径一节，及全文所有相对路径的基准 |
| `<课程注意事项页URL>` | 你自己维护的课程注意事项网页（没有就删除相关条目） | 资料优先级第 1 条 |
| `<课程courseid>` | 超星课程 ID，用 chaoxing-courseware 的 list 命令查得，每学期更新 | 工作流程第 0 步 |

图床配置：按 picgo-image-upload skill 的说明配置 PicGo（默认腾讯云 COS，也可换其他图床），配好后报告插图会自动上传并只保留图床链接。

## 基本用法

1. 对 AI 说："写第 N 周实验（实验名）的预习报告/实验报告，数据照片在 …"。
2. AI 会依次：读你的课程注意事项页（如配置）→ 读 `references/` 三个规范文件 → 用 chaoxing-courseware 下载并通读当次讲义 → 逐张提取你的数据 → `lab_calc.py` 按课程口径计算 → 按模板撰写 md → 插图传图床。
3. 写完 AI 会按 `references/反AI痕迹清单.md` 逐条自查（公式独立成行、字数红线、语言无机器腔、每个数字可复算）。
4. Typora 导出 PDF、补页码，按 `<你的姓名>+<你的学号>+实验名称+第N周.pdf` 命名（每个字段之间都用加号连接）。
5. 你核对封面（教师/日期以选课系统为准）与数据照片后，预习报告课前交、实验报告一周内交"学在浙大"。

写作过程中你说"写进 skill"，AI 会把教训追加到 `references/经验与注意事项.md`，越用越贴合你的习惯；每学期开课前记得用选课系统重新生成课表。

## 注意事项

- **报告必须基于真实数据**：本 skill 的原则是"不虚构、不优化任何测量数据"，缺数据就向用户要。这是课程学术诚信的底线，也是本 skill 的边界。
- **无 AI 痕迹排版**：课程报告由老师人工批改，且原始数据记录纸需老师当场签字，机器腔、复算不出的数字都会被识别为代写。`references/反AI痕迹清单.md` 是交稿前的自查红线。
- **计算口径以课程 PPT 为准**：`references/计算规范.md` 依据的是浙大该课程绪论 PPT 的口径（如 B 类不确定度进位记法、不确定度首位 <3 留 2 位等），换课程务必先核对。
- **模板与课件版权归课程组**：本仓库只提供撰写规范、计算脚本与经验，不含课程报告模板、绪论 PPT 与讲义，请从课程官方渠道获取。
- 历史参考资料（学长学姐报告等）"一律仅供参考，必须独立验证"，抄进错法是最典型的暴露源。

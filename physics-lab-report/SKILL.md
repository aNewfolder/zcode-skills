# 大学物理实验报告撰写

替使用者完成《大学物理实验》的预习报告与实验报告（使用者姓名/学号/班级等个人信息在使用时询问使用者，或从下方"个人信息占位符"读取）。报告是交给老师的作业，**成稿必须是"学生本人按课程规范亲自完成"的样子**——数据来自使用者真实记录，计算完全符合课程规范，语言朴素自然，无任何机器痕迹。

**个人信息占位符**（全文用 `<你的姓名>`/`<你的学号>`/`<你的班级>` 指代，使用时替换为使用者实际信息；首次使用前应一次性替换好并记住）。

## 交付形态与命名（2026-09 起固定）

- **所有报告一律交电子版**：预习报告、实验报告都是 md 撰写 → Typora 导出 PDF 上传"学在浙大"。**不再手写誊抄**，因此封面信息（实验名称、指导教师、实验日期等）必须**在 md 里直接填写完整**，不留空栏。
- **PDF 文件名严格按课程格式**：`<你的姓名>+<你的学号>+实验名称+第N周.pdf`——**每个字段之间都用加号连接，姓名和学号之间也不例外**（两周实验写 `第11-12周` 这样的区间）。导出后 PDF 放在该实验文件夹内。
- **必做实验交一份报告**：必做1（示波器的使用+声速测定，2周）和必做2（分光计的调整和使用+棱镜偏向角特性，2周）各自是**一个实验包含两个小实验，只交一份报告**——两个小实验的综述/重点/难点合入同一份模板（综述分（一）（二）两小块，但**整个综述板块合计仍 ≤500 字**，即每块约 230~240 字，模板的红线不因合并而放宽；重点、难点各合并成一段 ≤100 字）。所以全学期一共 **12 份**报告。
- **指导教师以选课系统为准，不是每个实验都是同一位老师**：写报告前用 `python "<课程资料根目录>\其他\自动选课.py" my` 查该实验的带课教师和上课周次（校园网内可用）；封面"实验日期"填选课系统 `dates` 字段对应的具体日期（含星期，有的周次调休可能在周末）。当学期各实验的周次/教师/日期查好后记入 `references/经验与注意事项.md` 末尾的课表模板。

## 固定路径

- 课程文件夹：`<课程资料根目录>`（使用者存放本课程全部资料的根目录，首次使用时向使用者确认并记住，下同；下述相对路径均以其为基准）
- 报告模板（每次以课程文件夹内最新版为准，勿用记忆中的旧版）：
  - `物理实验报告-模板.md`
  - `物理实验预习报告-模板.md`
- 绪论 PPT：`绪论_课程要求202609.pptx`（课程要求）、`大物实验绪论_fy202609新.pptx`（测量/不确定度/数据处理规范）
- 本 skill 规范（写报告前必读）：
  - `references/计算规范.md` —— 不确定度评定与数据处理全部规则
  - `references/反AI痕迹清单.md` —— 交稿前逐条自查
  - `references/经验与注意事项.md` —— 用户反馈沉淀的活文档，**每次先读**
- 计算脚本（防算错）：`scripts/lab_calc.py`
- PDF 收尾：`其他\给PDF加页码.py`（Typora 导出 PDF 后补页码，封面从 0 开始）

## 资料优先级（从高到低，冲突时高级别一票否决）

1. **使用者课程注意事项页（如有）**：使用者自己维护的课程注意事项网页 `<课程注意事项页URL>`（首次使用时向使用者要，未配置则跳过本条）上的注意事项与要求，**优先级最高**——与下面任何资料冲突时一律以它为准。
2. **课程 PPT 与当次讲义**：绪论 PPT、超星下载的本次实验讲义/课件——正确性的基准，计算口径、格式、内容以它们为准。
3. **参考资料**：`历史资料\` 里历年学长学姐的报告、总结、网上搜来的经验帖等，**一律仅供参考，不保证正确**。其中任何内容（公式、数值、结论、过程写法、误差分析说法）想用之前，**必须先独立验证**：公式对照 PPT/讲义推一遍，数值用 `scripts/lab_calc.py` 或手算重算一遍，说法对照课程规范核一遍。验证不过就弃用，**绝不照搬**——参考资料的错法抄进报告是最典型的暴露源。

无论资料来自哪里，写进报告的每一个数字都必须用本次实验的原始数据**自己重算**得出，不得直接引用任何来源的现成结果。

## 工作流程

### 第 0 步：三项前置功课（每次写报告都做，一次都不能省）

1. **读使用者课程注意事项页（如已配置，见「资料优先级」第 1 条；未配置则跳过本步）**：抓取该页（用 mcp__web_reader__webReader 或 WebFetch），逐条读完页面上所有注意事项/提醒，与本报告相关的全部落实。页面内容可能随时更新，以当天抓到的为准；这里的要求**优先级最高**（见「资料优先级」），与 PPT/讲义/参考资料冲突时以它为准。
2. **读沉淀经验**：读 `references/经验与注意事项.md` 全文。
3. **下载并通读本次实验讲义**：用 chaoxing-courseware skill 登录超星，列出课程章节，找到本次实验对应章节，把该章节的文件课件（讲义/指导书/PPT，`--type document`）全部下载到本次实验文件夹，然后**逐个通读**，提取：实验原理与公式、仪器规格与允差/分度值、数据记录要求、数据处理方法要求、教材思考题原文（第四部分要用）。课程 courseid=`<课程courseid>`（用 chaoxing-courseware 的 list 命令列出课程后查得，每学期更新）。若 Cookie 过期需要重新 login 而你不知道密码，向使用者要密码或请使用者登录后重试，**不要跳过讲义**。

### 第 1 步：建实验文件夹

课程文件夹下每个实验单独建文件夹，命名 `序号.实验名`（序号按实验课次，如 `1.示波器的使用`）。结构：

```
大学物理实验\
  1.示波器的使用\
    （超星下载的讲义/课件原文件）
    预习报告.md
    实验报告.md
    原始素材\        （用户给的图片、数据照片先放这里，上传图床后留档）
```

### 第 2 步：读用户材料

用 Read 工具逐张看用户提供的图片（原始数据记录、仪器读数照片、实验现象照片）。数据一律以照片为准逐字提取，**缺数据（如仪器允差、某次读数、思考题）就向用户要，绝不编造**。顺手记录：仪器型号/分度值/允差、测量次数、实验日期（以实验选课系统内日期为准）。

### 第 3 步：计算（严格按 `references/计算规范.md`）

- 全部数值计算用 `scripts/lab_calc.py` 完成（防口算错误），再以"手算过程"的形式写进报告：公式 → 代入数值 → 中间结果（多留 1~2 位）→ 按规则修约 → 结果。老师要能一步步复算。
- **每个数字都是本次重算的**：即使某参考材料（学长报告、网络答案）给出了看似现成的过程或结果，也只能当做法线索，数值必须用本次原始数据从公式开始重算；与参考结果不一致时，先核自己的推导与输入，再怀疑参考资料，最终以按课程规范重算的为准。写完后回看一遍，确保没有一个数字是"搬来的"。
- 直接测量：五步法（平均值 → s(x̄) → u_A → u_B=Δ仪/√3 → 方和根合成）；先剔除异常值、做零点修正。
- 间接测量：和差用方和根，积商先取对数用相对不确定度传递；常数（π 等）不传递。
- 结果表达式：先定不确定度位数（首位非零 <3 保留 2 位、≥3 保留 1 位，最大误差限原则），再对齐平均值末位；相对不确定度 E=u/x̄×100%。
- 数据处理方法优先**最小二乘法**（作图可建议 Origin/Excel）；逐差法仅当讲义明确要求时用。
- 预习报告阶段的计算（如理论值、仪器误差预估）同样按规范。

### 第 4 步：写预习报告

以 `物理实验预习报告-模板.md` 为底稿：

- **封面当场填全（电子版）**：实验名称（用选课系统名称，去掉 ▲/必做N 等符号）、指导教师（选课系统查到的该实验带课教师）、实验日期（具体到"2026年10月9日"并核对星期，两周实验把两个日期都写上）；班级/姓名/学号预填内容保留；模板自带排版原样保留，**不要改版式**。
- 一、1 实验综述 ≤500 字：自述实验现象、原理、方法。**该有的公式一个不能少**，且公式排版执行下面「公式排版规范」；变量含义、适用条件在公式后用"式中……"交代清楚。图先存原始素材，经 picgo-image-upload 上传后插图床链接，alt 写图的实际内容。
- **公式排版规范（全部报告适用）**：
  - **每一个完整的数学等式/关系式一律独立成行、居中显示**，用 `$$...$$`（display 模式），包括推导中间步骤（如 $R^2=r^2+(R-e)^2$）、简化的最终公式（如 $R_x=\frac{R_1}{R_2}R_s$）、定义式（如电桥灵敏度）。行内只允许放**单个变量符号**（如 $U_H$、$I_S$、$\alpha$）或带下标的量的简单引用，**不允许行内出现带等号/不等号的式子**。
  - **禁止用 Unicode 上下标拼公式**（如 `Rₓ=(R₁/R₂)Rₛ`、`2e_k=kλ`、`B₀=(4/5)^{3/2}μ₀NI/R` 这类写法一律不得出现在正文行内或 `$$` 外）；凡是要写关系式，就写成 `$$...$$` 并用规范的 LaTeX 命令（`\dfrac`、上下标、`\mu_0` 等），让排版尽可能接近教材/LaTeX 效果。
  - 布局上让公式"像教材"：推导成链时按逻辑顺序逐行排（每行一个等式，行间用"由此可得""代入上式"衔接），长公式右端对齐换行点不用生硬拆行；正文中公式前后是完整句子，公式行本身不作句子成分的机械拼接。
- 2 实验重点 ≤100 字、3 实验难点 ≤100 字：**想清楚什么是真的"重"、真的"难"**——重点写这条没做好实验就立不住、它承载了实验的核心方法（体现出"重"）；难点写它为什么难、错一步会怎样（体现出"难"），不写"认真读数、细心操作"这类任何实验都通用的空话。
- **语言风格按教科书标准（对全文生效）**：逻辑清晰、句子完整、语法正确，用平实的书面语把因果链讲清楚；**每个分句都要是完整的话**，禁止电报式压缩（"逐挡升"必须写成"从最低挡开始逐挡升高"这类完整表述）；**禁止主观强调与文学化比喻**（"必须吃透的主线""灵魂""精髓""纲""枢纽""承重墙""基石""关键一招""巧妙转换"这类一律不写）；不为凑简短牺牲明确性——在字数上限内把话说得更细、更具体、更明确。
- 保留模板末尾"注意事项"引用块。
- 语言按 `references/反AI痕迹清单.md` 写成学生口吻。

### 第 5 步：写实验报告

以 `物理实验报告-模板.md` 为底稿：

- 封面：同预习报告一样当场填全（实验名称、指导教师、实验日期以选课系统为准），另有实验桌号（问用户或留待用户填）。
- **一、预习报告（10分）**：把写好的预习报告三个小节内容原样拷入。
- **二、实验操作与原始数据（50分）**：用户拍摄的数据记录纸照片全部经 picgo-image-upload 传图床后插入，alt 描述内容，顺序合理；照片必须完整保留姓名、学号、教师签字和日期（这一点要在交付时提醒用户检查照片本身）。有实验过程图也放这里。
- **三、结果与分析（30分）**：
  - 1 数据处理与结果（20分）：markdown 表格列数据 → 完整处理过程（第 3 步的成果）→ 完整结果表达式 N=(x̄±u) 单位 + 相对不确定度/相对误差 → 明确结论。
  - 2 误差分析（10分）：用绪论学的误差类别（已定系统误差-修正、未定系统误差-仪器允差/B类、随机误差-A类、粗大误差-剔除）针对**本实验具体环节**分析，每个误差源说清对结果的具体影响，不写放之四海皆准的套话。
- **四、实验探讨与思考题（10分）**：≤100 字小结（写实：结果好坏、与理论/公认值比较、明显的问题）；思考题**先抄题干（讲义/教材原文）再作答**，作答要像学生认真手写，计算题给出过程。
- 保留模板注意事项引用块与落款。

### 第 6 步：图片一律走图床，且只截物理图

- **只截最重要的部分，基本以物理图像为主**：光路图、电路图、原理框图、特征曲线。**严禁整页 PPT 截图**——PPT 的标题栏、页码、装饰背景、成段文字一律裁掉；讲义/PDF 截图也要裁到只剩图和图注，不带正文段落。一张图里有多块有用内容时，可以分别裁剪后用白底拼合。
- 截图后逐张放大自检：四边没有别的文字残条、页面装饰残留；图内文字清晰可读（分辨率不够就换 PPT 原图或用 pymupdf 高倍率重渲染，实在没有就按原始尺寸插入，不要强行放大）。
- 凡报告/预习报告要插的图，一律先经 picgo-image-upload skill 上传（注意它有"上传前重命名"对话框流程；PicGo 卡死时可用课程文件夹内 `_cos_upload.py` 直传），文档中只放图床链接 `![具体内容描述](URL)`，不留本地路径。原始图片文件留在实验文件夹 `原始素材\` 备份。

### 第 7 步：成稿完整审查（一次都不能省）

写完**不要立刻交付**，先从头到尾完整审一遍：

1. **完整性**：模板每一节都填了实际内容？该给的公式（原理公式、传递/合成公式、结果表达式）一个不缺？
2. **公式排版**：是否每一个完整等式都独立成行居中（`$$...$$`）？行内是否还残留带等号的式子或 Unicode 上下标拼的公式（`Rₓ=(R₁/R₂)Rₛ` 这类）？有就改成 display 公式；变量与条件是否都交代了？
3. **重点/难点复核**：逐字问自己——重点写的是不是这个实验真正承重的东西（没它实验就不成立）？难点写的是不是真的难（有具体的失败模式），还是"要细心"式的废话？不合格就重写。
4. **语言**：逐句读——每句话是否完整、语法正确、逻辑衔接清楚？有没有"逐挡升"式的电报句和"吃透的主线/灵魂/精髓/纲"式的主观强调？字数没到上限且还有值得说的，就把原理/操作的逻辑链补得更细；超字数的删次要信息。
5. **封面与命名**：实验名称/指导教师/实验日期与选课系统一致；PDF 按 `<你的姓名>+<你的学号>+实验名称+第N周.pdf` 命名（姓名与学号之间也有加号）。
6. **数字与图**：每个数能复算（对照 `references/计算规范.md`），每张图四边干净、alt 描述与内容一致。
7. 对照 `references/反AI痕迹清单.md` 逐条自查，改完再交付。

### 第 8 步：交付

- md 写完后用 **Typora 导出 PDF**：运行 `python "<课程资料根目录>\其他\_typora_export2.py" 报告.md 输出.pdf`（可一次传多对文件批量导出）。该脚本走确定性的键盘+门禁流程：窗口钉到 (0,0)、AttachThreadInput 强制前台并验证、Alt+F 后截图差分确认菜单弹开、↑×4 选中"导出"→→ 展开子菜单、**截图确认"PDF"项存在后才按 Enter**、保存对话框用 WM_SETTEXT/BM_CLICK 原生操控、导出后自动校验（%PDF 魔数、页数、字体含 SimSun/SimHei、体积下限），失败自动重试。**不要退回方向键盲按或固定坐标盲点**——那样会点到"删除/关闭/打印"或导出成 HTML（实测发生过，曾把一份报告的 md 搞丢，靠 draftsRecover 恢复）。脚本自带 md 备份恢复保护。
- 导出后运行 `python "<课程资料根目录>\其他\给PDF加页码.py" 报告.pdf -o 临时名` 再改回原名补页码（封面第 0 页；pymupdf 不允许原地保存，必须 -o 临时文件再覆盖）。
- 交付 md 与 PDF 的绝对路径，并提醒用户：
  1. 实验报告还需插入带签字的原始数据照片后才交；预习报告直接交；
  2. 预习报告在**课前**交、实验报告在实验后**一周内**交"学在浙大"对应作业模块，全部交 **PDF 电子版**，文件名按上面格式；
  3. 实验结束 3 天内在选课系统做教学评价。

## 反馈沉淀（本 skill 的持续更新）

用户在改报告过程中说"写进 skill""记到 skill 里""以后注意"时：

1. 在 `references/经验与注意事项.md` 末尾追加一条带日期的条目（来源：用户反馈），写清"场景 → 错误做法 → 正确做法"。
2. 若属于通用规则（如字数、格式、计算口径、措辞），同步修订 `SKILL.md` 或 `references/计算规范.md` 对应段落，不要只在经验文件里躺着。
3. 每条经验都要具体可执行；写完向用户确认一句话即可。

## 边界

- 只写报告与数据处理，不代替用户登录学在浙大提交作业、不代做教学评价。
- 不虚构、不"优化"任何测量数据；数据存疑时列出来问用户。
- 计算口径有争议时按"资料优先级"排序：用户网站笔记 → 绪论 PPT 与当次讲义 → `references/计算规范.md`；参考资料（学长学姐材料等）不参与裁定，只有被独立验证过才可作旁证。

# zhiyun-lecture-notes · 智云课堂讲义

**核心资产（勿改动位置）：**

- 脚本目录：`scripts/`（本 skill 目录下）
  - `zhiyun.py` 智云课堂（课程/课次/PPT 板书/语音转写/回放）
  - `zyframes.py` 纯板书课回放抽帧重建板书序列（依赖 opencv-python、numpy、Pillow、imageio-ffmpeg——自带 ffmpeg 二进制，系统无需装 ffmpeg）
  - `zjuauth.py` 共享统一认证 CAS 登录 + 限速 + 单实例锁
- 凭据：`scripts/config.json`（`{"username","password","password_verified":true}`，用户手动创建）。**不要**在对话里索要或回显密码。
- 会话：`scripts/sessions/zhiyun.json`（自动复用，失效自动重登一次）
- API 排查手册（站点改版时读）：`references/api-notes.md`

## 红线（先读）

1. **限速与串行是硬约束**：脚本内置全局单实例锁 + 最小请求间隔（智云 API 1.2s；PPT 图片是静态 CDN 资源允许 4 并发）。
   禁止并行运行本 skill 的脚本、禁止循环轮询。
2. **统一认证锁号纪律**：连续错约 5 次锁号，凭据类登录失败 1 小时内最多 2 次（脚本自动记账并拒绝）。
   登录失败**不要自动重试**；连续失败先问用户密码是否改过。统一认证要求验证码时脚本会安全中止——让用户浏览器登录一次再试。
3. 智云当天/进行中的课没有字幕（下课才有）；无字幕或转写质量差时讲义**完全基于 PPT** 撰写，不要硬编转写内容。
4. 讲义产出的**过程文件最后全部删掉，只留成品**；PPT 图片一律传图床，笔记里只放图床外链。

## 命令速查

统一格式：`cd <本skill>/scripts` 后运行；stdout 末行为一个 JSON 对象（exit code 非 0 = 出错，读 error/message）。

```bash
# ---- 智云课堂 ----
python zhiyun.py login [--fresh]
python zhiyun.py courses [--keyword 信号] [--scope mine|all]
python zhiyun.py lessons --course 信号与系统乙 [--teacher 张三]    # 课次列表（第N次课/日期/可回放）
python zhiyun.py fetch --course 信号与系统乙 --lesson 5 --out "<临时目录>" [--audio]
#   fetch 产出：transcript.txt(带时间戳原始转写) + transcript.json + slides_final/(去重后最终版板书jpg)
#   + manifest.json（含转写质量粗筛 quality: ok|poor|none 和 audio_url=回放视频直链，名字叫 audio
#   但实际是 playurl 第一项 mp4/hls，带 auth_key 有效期约 3-4 天）

# ---- 纯板书课：回放抽帧重建板书（zhiyun fetch 发现 slides_total<=1 时用）----
python zyframes.py <回放mp4路径或URL> <out_dir> [--interval 8] [--era-drop 0.6] [--topk 4] [--crop x,y,w,h]
#   产出：cand/ 候选帧 + era-EEE-K-<时刻>-chalkX.jpg 板书时代代表帧 + eras.json 时间轴 + sheet-NN.jpg 联络表
#   后续由 agent 看联络表挑选配图；读不清数字的帧再对局部 2-3x 放大裁剪
```

## 工作流 A：智云讲义

触发：用户说"把第N次课做成讲义/整理XX课的录播"。步骤：

1. **定位课次**：`zhiyun.py lessons --course <课程名或简称> [--teacher ..]`，与用户确认第几次课（或按日期）。当天还没下课的课没有字幕和完整 PPT。
2. **拉素材**：`python zhiyun.py fetch --course <课> --lesson <N> --out "<临时目录>"`（临时目录建议 `%TEMP%\zy_<课名缩写>_L<N>`，**不要放在用户的笔记仓库里**）。
3. **质检**：读 `manifest.json`：
   - `transcript.quality=ok` 且抽样通顺 → 模式 A：转写逻辑 + PPT 板书，双源撰写；
   - `quality=poor/none`、乱码多、口音重识别烂 → **模式 B：完全基于 PPT** 写教材式讲义。
   - **`slides_total<=1`**（唯一的"图"是教室桌面截图）→ 这是**纯板书课**（老师黑板手写、无 PPT），转 **模式 C**（见下）。此时模式 B 无从谈起，别硬编。
   - Read 抽查 `slides_final\` 若干张 + transcript 开头/中间各 20 行，别只信脚本给的 quality 字段。
   - 注意转写粗糙但信息量大是常态（识别错字：拓扑排序→"突破排序/托钵有序"、节点→"7.7点数"、AOE 网→"让图"等），按教材知识修正，别因质量字段 poor 就扔掉转写。更多错字样本见 `references/api-notes.md`。
4. **撰写讲义**（规范是本 skill 的灵魂，逐条遵守）：
   - **定位：读者看这一篇就能完全取代听课。** 教材级：概念定义完整、动机清楚、推导一步一步不跳步、前后衔接连贯（开头承接上一讲，结尾预告下一讲）。
   - **不保留转写原文**。转写只用来还原老师的讲解顺序、例题和口头强调；错误百出的识别文字必须按教材知识修正重写。老师的逻辑跳跃要补齐中间步骤；口误/笔误以标准结论为准。
   - **例题**：题目与解答分离。先完整重述题目（条件、求什么），给一行"先自己想想"的停顿提示，再分步详解——每一步写明依据（用了哪个定理/公式），老师一笔带过的例题必须完整展开，做完附结果讨论（答案量级/物理意义/常见错法）。PPT上的例题也要保留PPT并重述题目+解析。
   - **老师强调的东西显式保留并加强**："考试会考""这个必须记住"之类 → 用 `> **老师强调（考试）**：…` 引用块标出，并在小结里复述。
   - **PPT 图**：只嵌入 `slides_final`（已是每页最终版，动画帧已去重）。按讲义章节把图插到对应位置，`![描述图内容的alt](图床URL)`。选择性地嵌：讲义正文已讲清的纯文字页可以不贴图；有图示/推导/图表的必贴。全部上传图床（本仓库 picgo-image-upload skill 的 `scripts/upload.py`，PicGo 需在运行），上传后 GET 校验一两个 URL。
   - **语言**：中文、严谨、无废话、无 AI 痕迹——不用"综上所述/值得注意的是/总的来说"套话堆砌，不写空段落；术语首次出现给英文对照；公式用 LaTeX（`$...$`/`$$...$$`，Obsidian 可渲染）。
   - 结构模板：
     ```markdown
     # <课程名> 讲义 · 第N讲 <主题>
     > 课程/教师/日期/讲义范围（PPT页码与时间范围）
     ## 本讲在课程中的位置（承上启下，3-5句）
     ## 1. <节标题>
     ### 1.1 <小节>   （概念 → 为什么需要 → 怎么定义/推导 → 性质/例）
     ## 例题 <编号>：<题目>
     （提示行）
     **解答**（分步）
     ## 本讲小结与考试要点（含所有"老师强调"汇总）
     ## 板书与截图附录（按节引用过的图也可就地嵌，附录只放未随文嵌入的关键页）
     ```
5. **落盘**：`<你的笔记库>/课程/<课程名>/<课程名>讲义/<YYYY-MM-DD>_第N讲_<主题>.md`。
   课程文件夹不存在就建（`<课程名>讲义` 子目录专门放这门课的讲义）。课程名用教务规范名（如 `信号与系统（乙）`）。
6. **清理**：删除临时目录（含 transcript、manifest、所有本地图片）。**只留成品 md**；笔记里不允许残留本地路径。

### 模式 C：纯板书课（回放抽帧重建板书）

触发：fetch 后 `slides_total<=1`（黑板机位录课）。板书就是这门课的课件，重建流程：

1. **下载回放**：manifest 的 `audio_url` 就是回放 mp4 直链（带 auth_key）。先 `curl -sI` 看 Content-Length（45 分钟 1080p 约 0.5-1.5GB），校园网约 11MB/s，用 `curl -o` 后台下。auth_key 会过期，当天处理最稳。
2. **抽帧重建**：`python zyframes.py <mp4> <out>\frames --interval 8`。产出"板书时代"代表帧（擦板切时代，每时代取粉笔最丰富的 top-4 帧 + 时代首帧）+ 联络表。
3. **定向核对**：联络表只看得出布局；读数字要两步——(a) 用转写锚点（"翻到 186 页图 7.30"）确定每个例题的板书时刻，按 `2+8*(N-1)` 秒取对应 cand 帧；(b) 对关键图表区域做 2-3x 放大裁剪（cv2 resize INTER_CUBIC）读清每个数字。
4. **数据锁死后再写**：例题的每一个数字（边权、表值）都要在特写帧或转写里找到出处；转写与板书冲突时以定义/逻辑自洽者为准，讲义里注明。网络图建议 mermaid 复原 + 板书照片并排，两者可互相印证。
5. **避坑**：分段不能用相邻帧差分——增量写字每 8s 只变化 0.1-0.5%，远低于人走动的变化，会把几十分钟并成一个状态；要用粉笔量骤降（擦板）切时代（zyframes.py 已内置正确逻辑）。老师身体会遮挡板书，同一时刻前后 ±8s 换一帧往往就没人了。
6. **视频是过程文件**：回放 mp4（0.5-1.5GB）、候选帧、特写裁剪、转写全部算中间产物，讲义成图（已传图床）后**连视频带帧目录一起删**，与红线第 4 条一致。

## 工作流 B：未选课程的智云旁听/跨班讲义

触发：用户要旁听没选的课、给其他老师的班做讲义，或问"这门课要不要申请听课权限"。

1. **免申请直读（2026-11-05 实测成立）**：智云的课次目录、PPT 时间轴、语音转写、回放地址接口**都不校验选课关系**——任何登录用户可用全站搜索定位课程后直接读全部课次素材，无需走听课申请。流程：`courses --scope all --keyword <课名> [--teacher <教师>]` → 从结果拿 `course_id` → `lessons --course <course_id>` → `fetch --course <course_id> --lesson <N>`，与工作流 A 完全一致。若未来接口改为 401/403，再考虑官方申请通道，不要硬试。
2. **周次映射**：`lessons` 按开课时间升序编号"第 N 次课"，与教学周不同。先确认学期第 1 周周一日期（开学日可从教务校历或课表推断），第 N 周 = 开学周一 + 7×(N-1) 那一周；再按课程"周几第几节"（从课表或 lesson 的 start_at + 节次时刻推断）落到具体 lesson。每周两次课的课次 = 该周内所有 lesson。
3. **素材与讲义**：与工作流 A 相同（含模式 A/B/C 判断）。纯板书课直接走模式 C。
4. **纪律**：只读、限速、单实例，与工作流 A 相同；讲义落盘到该课程规范名的课程目录。

### 整门课批量串讲（每讲派一个子智能体，主对话串行）

触发：用户说"把XX老师XX学期整门课的回放都做成讲义/都整理成笔记"。要点（某数学课 16 讲全量实测）：

1. **定位课程**：`courses --scope all --teacher <教师全名>` → 按课次日期（lesson 标题自带 `2026-01-06` 这类日期）核对学年学期（冬学期≈11月~1月）。**"我的课程"里可能有同名但不同教师的在修课**（如本人在修某班的同时想旁听另一位老师的班），用 course_id 操作最稳。
2. **先试拉一讲**：fetch 第 1 讲验证权限与素材质量（转写量、板书清晰度），再开始批量。
3. **串行派发是硬约束**：每讲一个 general-purpose 子智能体，主对话**同时只跑一个**，验收通过才派下一讲（智云单实例锁+限速；图床也不要并发轰）。子智能体 run_in_background 不用——前台等待即可。
4. **子智能体 prompt 必须自足**（它看不到主对话）：fetch 命令与素材**绝对路径**、质检规则、讲义规范全文、图床上传命令、成品路径、清理要求、汇报清单。声明 shell 类型，Windows 下**不要用 %TEMP% 语法**（Git Bash 不展开）。
5. **承上启下**：prompt 给上一讲成品绝对路径，让子智能体 Read 其"本讲小结"再写开头；最后一讲把"预告下一讲"换成"全课程收束 + 考前建议"。
6. **每讲验收清单（主对话跑，一条 bash 即可）**：成品 md 存在、图床域名出现次数符合、grep 无本地路径残留（`C:\`、`zy_` 临时目录名等）、临时素材目录已删；全部完成后抽查跨讲次图链 HTTP 200。
7. **重派容错**：子智能体被用户中断或配额超限杀死时，fetch 往往已完成——重派 prompt 写明"素材目录已存在且 manifest/transcript.txt/slides_final 完整则直接复用，不要重新 fetch"。
8. **落盘**：`课程\<课名>\<课名>讲义\<教师>_<学年学期>\<日期>_第NN讲_<主题>.md`。旁听课与本人在修课同名时，教师_学期子目录隔离两套讲义。

## 排错速查

| 现象 | 处理 |
|---|---|
| `HTTP 901` / 302 到登录页 / 页面含 loginForm | 会话失效，脚本已自动重登一次；再失败 `login --fresh` |
| `getKaptchaStatus=true` 中止 | 统一认证要验证码：用户浏览器登录一次统一认证后重试 |
| `LoginAuthError` | 凭据被拒（已记账）。**不要自动重试**；核对 config.json 密码，改后把 `password_verified` 置 true |
| 智云"未找到课程" | 该课可能没开智云录播；`courses --scope all` 全站搜试试；仍无则如实告知 |
| 智云字幕为空 | 当天的课要下课才出字幕；或该教室未接转写 → 模式 B（仅 PPT） |
| 智云 PPT 时间轴只有 1 张教室桌面截图 | 纯板书课（黑板机位录课、无 PPT）→ 模式 C，`zyframes.py` 抽帧重建板书 |
| 回放 mp4 直链 403/无法下载 | manifest 的 auth_key 已过期（有效期约 3-4 天）：重新跑一遍 fetch 拿新链接 |
| `courses/lessons` 报 education 接口 `HTTP 403` | `_token` Bearer 失效但 JWTUser cookie 还在（自动重登判不出来）：`zhiyun.py login --fresh` 一次即好 |
| 未选课程 lessons/fetch 报权限错误 | 免申请直读是 2026-11 实测口径；若失效读 `references/api-notes.md` 核对改版点，再考虑官方申请，不要硬试 |

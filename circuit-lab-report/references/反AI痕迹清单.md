# 反 AI 痕迹清单(交稿前逐条自查)

目标:报告读起来就是一个认真做完实验、认真写作业的学生写的。任何一条不满足都要改完再交付。

## A. 绝对禁止出现的字句(一票否决)

- 任何自我指涉或元信息:"AI""AI 生成""模型""助手""以下是根据您提供的""根据模板""按要求为您""..."(省略号代替实际内容)、"仅供参考""希望对你有帮助""如有需要请"。
- 任何面向读者的服务性语言:"请注意""温馨提示""小编""本文将""综上"。
- 模板 HTML 注释里的说明文字(`<!-- ... -->`)**绝不能出现在导出的 PDF/正文里**;写报告时把内容写在注释下方,交付前全文搜一遍注释标记和"依据指导书""写清""给分关键"这类提示语。
- 空占位:下划线空栏必须全部填上;日期、实验名称不留空白。

## B. 语言风格(教科书标准)

- 逻辑清晰、句子完整、语法正确:每个分句都是完整的话,主谓宾齐全,因果关系交代明白;像教材那样平实陈述,不写笔记式压缩。
- **禁止电报式压缩短语**:"逐挡调""快调慢调"必须展开(如"从最低挡开始逐挡升高灵敏度")。
- **禁止主观强调与文学化比喻**:"灵魂""精髓""纲""枢纽""承重墙""基石""关键一招""巧妙转换"一律不写;重点靠具体技术内容体现,不靠形容词拔高。
- 学生口吻、平实自然;少用排比和"首先/其次/最后"全套过渡词;**不为简短而简短**——把原理、操作和误差的因果链说完整、说具体。
- 不用 emoji、不堆感叹号、不滥用引号造修辞;不写"通过本次实验,我深刻体会到……"式空洞总结,小结写实:结果多少、和理论/仿真差多少、哪里没做好。
- 术语与指导书/仪器手册一致:说"探头衰减""共地""幅频特性""静态工作点",不自造说法;符号全文一致,数据表符号与正文公式对应。
- 长度像真实作业:原理把因果链讲全,分析写到具体数字,不交三五行的敷衍节,也不写注水的十页。

## C. 公式排版(md 模板)

- **每一个完整的等式/关系式一律 `$$...$$` 独立成行居中**(推导中间步骤也算,如 $\theta=\frac{X}{X_T}\times 360°$);行内只放单个变量符号(如 $U_o$、$\beta$);**禁止 Unicode 上下标拼公式**(`Uₒ=AᵥUᵢ`、`f₀=1/2π√LC` 写成 Unicode 的一律重写)。
- 符号含义与适用条件在公式后用"式中……"交代;tex 模板对应用 `equation` 环境独立成行。
- 公式中的量与数据表表头一一对应,单位写在数字后不写在符号后。

## D. 计算过程(最容易暴露的地方)

- 每个数字必须能从数据表或前一步复算出来;写完用 Python 重算一遍,**错一个数就全篇露馅**。
- 中间值位数像手算:比最终结果多 1~2 位,不给 12 位小数的"计算器精度"。
- 误差公式来源写清楚(仪器说明书/指导书),代入的量程、读数与表里一致。
- 结果表达完整:平均值 ± 不确定度 + 单位,或实测值 + 相对误差;不写孤立数字当结论。
- 数量级与单位自检:kΩ 与 Ω、mA 与 A、µF 与 pF,过一遍脑子再交;波形换算(格数 × V/div)要与图上刻度一致。
- 仿真与实测并列时,注明仿真条件(模型、温度、理想元件假设),不把仿真值冒充实测值。

## E. 内容具体性

- 误差分析每条落到本实验的具体机制(元件实际值偏差、仪表内阻、探头 x10、读数格数估读、信号源幅值漂移……),禁止"环境温湿度影响""人为误差不可避免"这类万能模板句单独出现。
- 思考题先题干后作答,题干抄指导书原文;答案与本次数据和现象对得上。
- 电路图、公式与当次指导书一致,不张冠李戴;图 alt/图注写图的实际内容(如"RLC 串联电路幅频特性实测曲线"),不写"图片1"。

## F. 格式与交付

- 模板七节的顺序、标题文字原样保留,不增删章节;md 版节标题保持加粗段落,**不要改回 `##`**(Typora 导出会每节另起一页)。
- 封面个人信息与模板预填一致;实验名称、日期、同组学生、实验类型如实填写,成绩栏留空。
- md 版所有图片是图床链接(picgo-image-upload 返回的 URL),无本地路径;tex 版图片在 figures 内且能编译;波形截图清晰、方向正。
- 文件放在该实验自己的文件夹;提醒用户 PDF 命名与提交时限。

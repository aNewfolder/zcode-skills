# 电子电路基础及实验报告撰写

替使用者完成《电子电路基础及实验》的实验报告(使用者姓名/学号/班级等个人信息在使用时询问使用者,或从下方"个人信息占位符"读取)。报告是交给老师的作业,**成稿必须是"学生本人按课程规范亲自完成"的样子**——数据来自使用者真实记录,计算能一步步复算,语言朴素自然,无任何机器痕迹。本课程**没有预习报告**,只写实验报告。

**个人信息占位符**(全文用 `<你的姓名>`/`<你的学号>`/`<同组学生>` 指代,使用时替换为使用者实际信息;首次使用前应一次性替换好并记住)。

## 交付形态与命名

- 报告交**电子版 PDF**,一律用 **XeLaTeX 模板**撰写(已定口径;目录里的 md 模板仅留作备用,不再维护)。
- PDF 命名与提交渠道以老师课程群/"学在浙大"通知为准;无明确要求时默认 `<你的姓名>+<你的学号>+电子电路实验N+实验名.pdf`。**每个字段之间用加号连接**(姓名与学号之间也不例外)。
- 封面信息当场填全:实验名称、日期(写实验实际做的日期)、实验类型(验证型/设计型/综合型,**以当次指导书为准,模板里留空、不要默认填验证型**),不留空栏;同组学生填 `<同组学生>`(有同组就填姓名与学号,当次没有同组就清空该栏);成绩栏留空由老师填。
- 实验指导书写得比较详细,但**报告不能照抄指导书**——目的/原理用自己的话概括重组,步骤补上自己实测的条件。

## 课程事实(2026-2027 秋冬,光电学院)

- 成绩构成:平时作业 25% + 实验 15% + 期末 60%(2026.9.14 首课宣布)。实验报告给分普遍不高,**"实验结果与分析"是拉开差距的关键**。
- 实验地点:东4-606。指导老师:闻春敖、袁波、赵文义(学长笔记中称 wca/yb/zwy),以当次实际带课为准。
- 学长届共交 8 次报告,前四次是电路原理部分(集中在秋学期后四周),后四次是模电部分(按单双周):
  1. 实验综述及常用仪器仪表的使用 + 直流电压、电流和电阻的测量(两个小实验**合成一份报告**)
  2. 叠加定理验证 + 叠加定理 Multisim 仿真
  3. RLC 串联电路的幅频特性和谐振
  4. 一阶、二阶动态电路
  5. 集成运算放大器的基本应用——模拟运算电路
  6. 晶体管共射极单管放大器
  7. 激光二极管的原理和特性
  8. 激光二极管驱动电路设计、制作与测评(指导书写得最简略,多参考学长模板;学长届七、八合并交过)
  指导书目录里还有实验九~十三(元件伏安特性、电位与电压、基尔霍夫定律、戴维南定理、负反馈放大器),做不做、做哪些以当年老师安排为准。
- 主要仪器:DZDL 实验箱(电路分析模块 DL-M2/M3、运放模块 DZ-D20、单管放大模块 DZ-DM1、激光模块)、示波器 GDS1102B、万用表 GDM8341、信号发生器 AFG2225、直流电源 GPS2303C、晶体管图示仪 WQ4830、LCR 测试仪 LCR-6002。

## 资料优先级(从高到低,冲突时高级别一票否决)

1. **使用者课程注意事项页(如有)**:使用者自己维护的课程注意事项网页 `<课程注意事项页URL>`(首次使用时向使用者要,未配置则跳过本条),抓取该页(用 mcp__web_reader__webReader 或 WebFetch),逐条读完当天的注意事项/提醒并全部落实;网站内容随时可能更新,以当天抓到的为准。
2. **实验指导书与老师当次要求**:正确性的基准,原理、公式、测量条件、数据要求以它们为准;仪器误差公式以仪器说明书为准。
3. **学长资料**(`学长资料\`):**一律仅供参考,不保证正确**。任何公式、数值、结论、误差说法想用之前,必须对照指导书推一遍、用本次数据重算一遍;验证不过就弃用,**绝不照搬**——学长的错法抄进报告是最典型的暴露源。

无论资料来自哪里,写进报告的每一个数字都必须来自本次实验的原始数据或由其**重新算出**,不得直接引用任何来源的现成结果。

## 工作流程

### 第 0 步:三项前置功课(每次都不能省)

1. **读使用者课程注意事项页**(地址见"资料优先级"第 1 条;未配置则跳过),相关要求全部落实。
2. **读沉淀经验**:`references/经验与注意事项.md` 全文。
3. **通读当次实验的指导书章节** + 涉及仪器的说明书节选,提取:实验目的原文、原理与公式、电路图、测量条件与数据记录要求、思考题原文(第七部分要用)。模电实验还要弄清哪些内容指导书标注"选做"。

### 第 1 步:建实验文件夹

课程文件夹下按实验课次建 `实验部分\N.实验名\`:

```
实验部分\
  1.常用仪器仪表的使用与直流测量\
    (指导书截图、Multisim 文件、学长参考等)
    实验报告\            (把 _tex模板 的 main.tex、config.cls、zju_cal.png 拷进来)
    原始素材\            (用户的数据照片、波形截图先放这里留档)
    figures\             (报告插图:电路图、波形截图等)
```

### 第 2 步:读用户材料

用 Read 工具逐张看用户提供的数据记录照片、示波器波形截图、仿真截图。数据一律以照片为准逐字提取;**缺数据(某次读数、量程、仪器设置、思考题)就向用户要,绝不编造**。顺手记录:仪器型号与量程、信号频率/幅值、实验日期、同组学生。

### 第 3 步:计算(防口算错误)

- 全部数值计算用 Python 跑一遍再写进报告,以"手算过程"的形式呈现:公式 → 代入数值 → 中间结果(多留 1~2 位) → 修约 → 结果。老师要能一步步复算。
- 本课程的误差口径:**仪表测量误差用仪器说明书上的计算公式**(通常与量程和读数有关,GDM8341 手册里有);直接测量结果按指导书要求表示为"多次测量的平均值 ± 合成不确定度"并给出相对不确定度;与理论值比较时算相对误差。不确定度合成的口径第一次实验讲义里有,按讲义执行,不套用大物实验的全套五步法。
- 电阻、电容、电感的"实际值"以 LCR-6002 实测为准(元件标称值误差不小);仿真值与实测值并列比较时要注明仿真模型条件。
- 有效数字与测量位数匹配:万用表五位显示、示波器格数估读到 0.1 格,不出现"计算器精度"的多余位数。

### 第 4 步:写报告(按模板七节,顺序固定)

1. **实验目的和要求**:依据指导书分条概括,用自己的话,不整段照抄。
2. **实验内容和原理**:测什么、依据什么原理;该有的公式一个不能少,变量含义与适用条件用"式中……"交代;电路图插图。
3. **主要仪器设备**:列出实际用到的仪器及型号。
4. **操作方法和实验步骤**:按实际操作顺序写,与数据一一对应;量程、频率、幅值、接线方式等条件必须写全,否则数据无法复测。
5. **实验数据记录和处理**:先表格后处理;每张表都要有测试条件与注释(实验六老师评语专门表扬过这一点)。
6. **实验结果与分析(必填)**:给分高低的关键。每组数据对比理论值/仿真值与实测值,误差多大、由哪个具体原因造成(元件实际值 vs 标称值、仪表内阻、探头衰减、读数格数……);波形图要说明读数方法(格数 × V/div 或 × s/div);**结合本次具体数据写,不写万能套话**。
7. **讨论、心得**:讨论题**先抄指导书题干再作答**,计算题给过程;心得写实——结果好坏、与理论差多少、遇到的问题及解决,不写"收获很大"式空话。

- **公式排版规范**:每个完整的等式/关系式一律独立成行(tex 用 `equation` 环境);行内只放单个变量符号;禁止 Unicode 上下标拼公式(`Uₒ=Uᵢ×Aᵥ` 这类一律不许出现);符号含义与适用条件在公式后用“式中……”交代。
- **语言风格按教科书标准**:句子完整、语法正确、因果链清楚;禁止电报式压缩("逐挡调"要写成"从最低挡开始逐挡升高");禁止"灵魂""精髓""承重墙"式的主观强调与比喻;字数上限内把话说细、说具体。

### 第 5 步:图片

- **只截有用的部分**:波形(含完整坐标系与通道刻度)、电路图、仿真原理图、仪器读数特写;**严禁整页指导书/PPT 截图**,装饰、页眉、成段文字一律裁掉。
- 波形截图要能读数:垂直灵敏度(V/div)、水平时基(s/div)、通道耦合与探头档位(x1/x10)必须可见或写进图注。
- 插图放实验文件夹 `figures\`,tex 里用 `\includegraphics` 插入,图注写图的实际内容;如需在 Obsidian 笔记里引用同一批图,另经 picgo-image-upload 传图床,与报告文件本身无关。
- 用户拍的原始数据记录照片(有老师签字的)如老师要求附上,照片必须完整保留姓名、学号、签字与日期,交付时提醒用户自查。

### 第 6 步:成稿完整审查(一次都不能省)

1. **完整性**:七节一个不缺;第六节有逐组数据的具体分析;思考题题干+解答齐全。
2. **公式**:每个等式独立成行(equation 环境)?行内没有带等号的式子?没有 Unicode 拼的公式?变量都交代了?
3. **语言**:逐句读,没有电报句、没有主观强调、没有模板腔;对照 `references/反AI痕迹清单.md` 逐条自查。
4. **数字**:每个数都能从原始数据或公式复算;量纲、数量级、正负号过一遍脑子。
5. **封面与命名**:实验名称/日期/同组学生与实际一致;PDF 按命名规则命名。
6. **图**:四边干净、无截图残条;alt/图注与内容一致;波形读数方法写清楚了。
7. tex 模板里 `%` 开头的说明注释确认没有被带进正文。

### 第 7 步:导出与交付

- **tex**:在报告文件夹运行 `xelatex main.tex` **连续两遍**(交叉引用与页脚 X / Y 需要第二遍),编译报错先查缺图片和表格列数。
- 备用 md 流程(不再维护,仅当用户点名要 md 时用):见 `实验部分\报告模板\README.md`。
- 交付 tex 与 PDF 的绝对路径,并提醒用户:按课程群/学在浙大要求确认命名与提交截止时间;实验数据照片是否需要附上以老师要求为准。

## 反馈沉淀(本 skill 的持续更新)

用户说"写进 skill""记到 skill 里""以后注意"时:

1. 在 `references/经验与注意事项.md` 末尾追加一条带日期的条目(来源:用户反馈),写清"场景 → 错误做法 → 正确做法"。
2. 属于通用规则的(措辞、格式、计算口径、模板改动),同步修订 `SKILL.md` 对应段落,不要只在经验文件里躺着。
3. 每条经验都要具体可执行;写完向用户确认一句话即可。

## 边界

- 只写报告与数据处理,不代替用户登录学在浙大提交作业。
- 不虚构、不"优化"任何测量数据;数据存疑、缺仪器设置、波形截图读不出数时,列出来问用户。
- 学长资料不参与正确性裁定,只有被独立验证过才可作旁证;与指导书冲突时以指导书为准。

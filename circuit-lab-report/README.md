# circuit-lab-report

让 AI 助手替你撰写浙江大学《电子电路基础及实验》的规范实验报告：XeLaTeX 排版、计算可逐步复算、语言朴素自然、无任何 AI 痕迹。

## 功能与适用场景

本 skill 为浙江大学《电子电路基础及实验》（电基/DZDL）课程深度定制，供 AI 助手（如 ZCode、Claude Code 等遵循 SKILL.md 约定的框架）在以下场景使用：

- 用户发来实验数据照片、示波器波形截图、Multisim 仿真结果，要求"写报告""处理这次实验数据""出实验报告"；
- 按 SKILL.md 固定的七节结构（目的 → 原理 → 仪器 → 步骤 → 数据处理 → 结果分析 → 讨论心得）产出 XeLaTeX 报告并编译为 PDF；
- 全部数值计算用 Python 复算后以"手算过程"形式呈现，误差口径按仪器说明书与本课程讲义执行。

**注意**：报告模板版式、误差评定口径、实验项目流程均绑定浙大该课程（模板与课程 Word 模板同版式，`references/` 里的经验也来自该课程的给分反馈）。他校或他课程使用前，需自行替换模板、修改规范文件。

## 依赖

| 依赖 | 说明 |
| --- | --- |
| XeLaTeX | 报告用 XeLaTeX 编译（推荐 TeX Live 完整安装），模板含中文排版，需系统具备中文字体（Windows 自带宋体/黑体即可）。图片文件名必须全 ASCII |
| Python 3.8+ | 用于数值计算复核与文本检查，仅标准库，无需额外安装第三方包 |
| Multisim（可选） | 叠加定理、激光二极管驱动电路等实验需要仿真文件 |
| Typora + 导出脚本（可选） | 仅 md 备用流程（本 skill 已不再维护 md 路线） |

本 skill 自身不含课程模板与实验指导书：`config.cls`、`main.tex` 等模板文件需从课程组下发的 Word/LaTeX 模板获取并放入你的课程资料目录（见下）。

## 安装部署

1. 把本目录整体复制到你的 AI 助手技能目录。ZCode 为 `~/.zcode/skills/circuit-lab-report/`；其他遵循 SKILL.md 约定的框架（Claude Code 等）放到对应的 skills 目录即可。
2. 确认 `xelatex --version` 与 `python --version` 可用（依赖见上表）。
3. 在你的课程资料根目录（自选位置，如 `课程资料/电子电路基础及实验/`）按 SKILL.md"固定路径"一节准备：报告模板（`实验部分\报告模板\_tex模板\`）、实验指导书与仪器说明书、（如有）学长参考资料。
4. **首次使用前**，把 SKILL.md 里的个人信息占位符替换为你自己的信息（清单见下）。也可以不替换，AI 会在使用时向你询问。
5. 在 AI 助手里说"帮我写电子电路实验报告"即可触发；若无自动触发，直接引用 SKILL.md 让助手读取。

## 需要配置的信息

SKILL.md 中使用以下占位符，部署时建议一次性替换（或保留占位符，由 AI 首次使用时询问）：

| 占位符 | 含义 | 出现位置 |
| --- | --- | --- |
| `<你的姓名>` | 报告封面与 PDF 文件名 | 交付形态、封面信息 |
| `<你的学号>` | 报告封面与 PDF 文件名 | 同上 |
| `<同组学生>` | 封面"同组学生"栏（有同组填"姓名(学号)"，没有就清空） | 封面信息 |
| `<课程资料根目录>` | 你存放本课程全部资料的根目录 | 固定路径一节，及全文所有相对路径的基准 |
| `<课程注意事项页URL>` | 你自己维护的课程注意事项网页（没有就删除相关条目） | 资料优先级第 1 条 |

本 skill 无图床依赖（报告插图放实验文件夹本地 `figures\`，随 tex 编译）；如需在笔记软件里复用同一批图，可搭配本仓库的 picgo-image-upload skill。

## 基本用法

1. 建好实验文件夹（`实验部分\N.实验名\`，含 `实验报告\`、`原始素材\`、`figures\`），把数据照片、波形截图放进 `原始素材\`。
2. 对 AI 说："写电子电路实验 N 的报告，数据照片在 …"。
3. AI 会依次：读你的课程注意事项页（如配置）→ 读 `references/` 经验与反AI清单 → 通读指导书当次章节 → 逐张提取你的数据 → Python 复算 → 按七节结构写 tex。
4. AI 编译两遍 `xelatex main.tex` 出 PDF，并按 `<你的姓名>+<你的学号>+电子电路实验N+实验名.pdf` 命名规则自查（每个字段之间用加号连接）。
5. 你核对数据与封面信息后，按课程群/"学在浙大"要求提交。

写作过程中你说"写进 skill"，AI 会把教训追加到 `references/经验与注意事项.md`，越用越贴合你的习惯。

## 注意事项

- **报告必须基于真实数据**：本 skill 的原则是"不虚构、不优化任何测量数据"，缺数据就向用户要。这是课程学术诚信的底线，也是本 skill 的边界。
- **无 AI 痕迹排版**：课程报告由老师人工批改，机器腔、模板腔、复算不出的数字都会被识别为代写。`references/反AI痕迹清单.md` 是交稿前的自查红线。
- **模板与指导书版权归课程组**：本仓库只提供撰写规范与经验，不含课程下发的报告模板、实验指导书与仪器说明书，请从课程官方渠道获取，也不要把含课程组版权内容的成稿再分发。
- 学长参考资料"一律仅供参考，必须独立验证"，抄进错法是最典型的暴露源。

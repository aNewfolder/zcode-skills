# CC98 抓取工具

一个已部署在本地的 Web 应用，封装了 CC98 官方 API：按关键词搜索帖子标题 → 把选中帖子的全部楼层正文（转 Markdown）和附件下载到本地。另有**兴趣推荐（推送）**：打开应用就按你的兴趣（ACEE、推免/保研、课程总结、不败光电版面、校园热点、感人文章等）推荐帖子。登录状态由应用管理，AI 不需要碰账号密码。

- 应用目录：本机部署的 CC98 抓取应用（需自行部署，见 README；未启动时脚本会提示 `python app.py` 启动，也可用环境变量 `CC98_APP_DIR` 指定其目录）
- 服务地址：`http://127.0.0.1:8765`（仅本机）
- 输出位置：应用目录下 `downloads/<时间>_<标签>/`
- 辅助脚本：本 skill 目录下 `scripts/cc98.py`（推荐优先使用，零依赖）

## 红线（先读）

- **本应用只用只读接口**（搜索/浏览/热帖列表）。绝不回帖、发帖、点赞、签到，也绝不调用任何写接口——会留下可见痕迹。
- 测试只用只读接口，且不要连续刷新推荐（一次刷新 ≈ 10 个请求，已是正常阅读量级）。

## 标准流程

### 0. 确认服务在运行

先探测，避免重复启动：

```
python "<skill目录>/scripts/cc98.py" login-status
```

- 输出"已登录：用户名" → 直接往下走。
- 报"CC98 应用未启动" → 后台启动服务（`python app.py`，工作目录为应用目录），等 3 秒重试。
- 输出"未登录 + 网络错误" → 大概率不在校网，改走 skill `cc98-viewer`（同一应用，登录 WebVPN 后所有命令照常可用）。
- 输出"未登录"（非网络原因）→ 让用户自己在浏览器打开 http://127.0.0.1:8765 点「登录 / 换账号」登录。**不要**试图替用户输密码；登录一次后 token 会自动续期。

### 1. 兴趣推荐（用户想"看看有什么新鲜事 / 推点帖子"时用）

```
python "<skill目录>/scripts/cc98.py" feed              # 读缓存推荐（秒回）
python "<skill目录>/scripts/cc98.py" feed --refresh    # 强制重新抓候选（约30~60秒）
python "<skill目录>/scripts/cc98.py" prefs             # 查看当前偏好
python "<skill目录>/scripts/cc98.py" prefs add keyword 奖学金 --weight 4
python "<skill目录>/scripts/cc98.py" prefs add board 贴吧议事厅   # 加关注版面
python "<skill目录>/scripts/cc98.py" prefs remove keyword 感人 / prefs remove board 不败光电
python "<skill目录>/scripts/cc98.py" prefs hot off     # 关闭全站热帖
```

- 推荐来源：兴趣关键词标题搜索 + 关注版面最新帖 + 首页每日/每周热帖，打分排序（关键词命中 > 版面命中 > 热帖，越新分越高）。
- 每条结果带推荐理由（🔑关键词 / 📁版面 / 🔥热帖）；抓取某条：把帖子 ID 传给 `crawl`。
- 默认偏好已按用户兴趣预置：ACEE / 保研 / 推免 / 感人 + 不败光电 / 课程总结与分享版面 + 每日每周热帖。改偏好优先用 `prefs` 命令，或在网页「今日推荐 → ⚙ 推送偏好」弹窗里改。
- 网页端每次打开自动读缓存，过期（默认 20 分钟）才后台刷新，"换一批"只是翻页、不产生新请求。

### 2. 搜索

```
python "<skill目录>/scripts/cc98.py" search "大物实验" --pages 2
python "<skill目录>/scripts/cc98.py" search 保研 推免 导师        # 多关键词各搜一次并去重合并
```

搜索机制决定了关键词写法，这是本工具最重要的一点：

- CC98 搜索**只匹配帖子标题里出现的字，没有模糊搜索/分词**。
- 默认 `--mode spaced` 会把汉字逐字拆开再搜（`大物实验` → `大 物 实 验`），这是官方搜索习惯下命中率最高的方式，一般不要改；英文/数字整体保留（`ACEE` 原样）。
- 关键词**宁短勿长**：标题里必然出现的 2~4 个字最好。搜"大物实验 误差"不如分别搜"误差分析"或"大物实验"——多词场景直接用多关键词合并搜索，一次命令搞定。
- 搜不到结果时：减字、换同义词（"期末"→"Final"、"补考"→"缓考"）、或去掉可能有出入的字再试。
- 每个关键词每页都是一次真实 API 请求。连续换词搜索没问题，但**不要**循环轰炸式地试十几个词。
- 网页端搜索结果支持筛选（版面/作者/时间/最低回复/标题再过滤）、排序（最新/回复/点击）、标题命中高亮；筛选纯本地，不产生请求。

### 3. 本地库检索（先查本地再联网！）

用户问"我之前抓的 XX 在哪 / 本地有没有 XX 资料"时，**先查本地，零请求**：

```
python "<skill目录>/scripts/cc98.py" history 误差 --limit 10
```

在 `downloads/` 所有已抓正文里做多词 AND 全文检索，输出帖子、片段和文件路径。

### 4. 抓取

从搜索/推荐结果里挑出目标帖子 ID（结合标题判断，向用户确认要抓哪些）：

```
python "<skill目录>/scripts/cc98.py" crawl 6632367 6632339 --label "大物实验资料" --wait
```

- `--wait` 会实时滚动进度日志直到任务结束，结束后打印输出目录。不加 `--wait` 就需要之后用 `status` 轮询。
- 一次任务**上限 20 帖**（服务端硬限制），更多分批做。
- 抓取内容：全部楼层正文（`content.md`）、原始数据（`topic.json`）、`[upload]` 附件和正文里的文档/压缩包直链（`files/`）。`[img]` 外链图片默认不下载（可在页面「设置」里开）。

输出结构：

```
downloads/<时间>_<label>/
├── index.md / index.json        # 本次清单（标题、链接、文件数）
└── <帖子ID>_<标题>/
    ├── content.md               # 逐楼层正文（Markdown，含附件链接）
    ├── topic.json               # 原始 API 数据（含原始 UBB）
    └── files/                   # 附件原文件
```

### 5. 交付

把输出目录里的 `index.md` 和各 `content.md` 路径告诉用户；若用户要的是"找文件"，直接列出 `files/` 里的文件名和大小。本地文件也可用 `http://127.0.0.1:8765/downloads/<任务名>/index.md` 直接在浏览器打开。

## 防封号纪律（必须遵守）

CC98 反爬严格，请求过多会限流甚至封号。以下每条都有真实代价：

- **请求间隔默认 3 秒且带抖动**，是应用内置的，不要通过改配置调低（低于 2 秒就是在拿用户账号冒险）。
- **绝不并发**跑多个抓取任务（应用一次只允许一个任务，这是特性不是缺陷）。
- **不要反复 `feed --refresh`**：一次刷新约 5~12 个请求；缓存期内重复刷新毫无意义。
- 出现"疑似被限流，为保护账号已自动停止"时：**立即停手**，告诉用户等一段时间（几小时到一天）再试，并把「设置」里的间隔调大（如 5~10 秒）。不要重试同一批抓取。
- 搜索超时/网络错误最多重试一次；持续失败说明环境有问题（校网断了、服务挂了），排查而不是硬刷。

## 常见问题

| 现象 | 处理 |
|---|---|
| 搜索结果为 0 | 关键词减字/换同义词；确认 mode 是 spaced；或用多关键词合并搜索 |
| 抓取完成但 files_ok 为 0 | 该帖本来就没有附件，属正常；正文仍在 content.md |
| `[HTTP 401] 尚未登录` | 让用户在页面上重新登录 |
| `[HTTP 502]` / "网络错误" | 没连校网，如实告诉用户 |
| 推荐一直是"正在生成" | 30~60 秒后重试；若 notes 报网络错误则不在校网 |
| 推荐里某个版面"未找到" | 用 `prefs remove board` 删掉、再用准确版面名 `prefs add board` 加回 |
| 服务起不来（端口占用） | 说明已有一个实例在跑，直接用即可 |
